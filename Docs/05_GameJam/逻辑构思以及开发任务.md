# 核心体验

## 游戏循环

> **入荒 → 寻兽 → 战斗 → 捕获 → 决策 → 撤离 → 养成 → 再入荒**

## 游戏支柱
- **支柱一：未知探索 ——「入荒寻兽」**

关键词：随机生态 / 异兽追踪 / 山海世界 / 高价值发现

- **支柱二：风险捕获 ——「得兽而归」**

捕获只是开始，成功撤离才永久获得

**捕获制造获得感，撤离制造珍惜感。**

- **支柱三：协作围猎 ——「共猎神兽」**

|   |   |
|---|---|
|**异兽等级**|**协作等级**|
|普通异兽|Solo 完整体验|
|稀有异兽|Solo / Duo|
|领主异兽|2～3人|
|神兽|3～4人 Raid|

**追踪 → 围堵 → 破坏部位 → 控制 → 镇压 → 捕获**

宠物之间还可以产生软职业分工：

- 龟：承伤 / 护盾
- 虎：破甲 / 爆发
- 鸟：治疗 / 辅助
- 族：控制 / 干扰
- 类：追踪 / 侦察

## 游戏目标

|   |   |
|---|---|
|**分期**|**目标描述**|
|短期目标|每局带回有价值的异兽 / 灵材 / 法宝|
|中期目标|构筑自己的异兽队伍，挑战更高等级禁区|
|长期目标|收集山海图鉴 + 培养顶级神兽 + 完成高阶 Raid|

# 逻辑优先级
## 地图&局内（联机逻辑）
1. 地图
	1. 玩家（Client）可以在联机状态下进入其他关卡。或者将玩家传送到Level的其他制定区域来实现。
2. 局内
	1. 通过Lyra phase GA相关逻辑实现局内逻辑。
	2. 每局游戏分为：
		1. 自由模式，没有任何限制可以随意进入其他地图探索。
		2. 计时模式，进入其他地图探索时有时间限制，在时间耗尽时，玩家会被强制传送出去。
3. 玩家死亡&复活
	1. [ ] 生命值归零死亡。
	2. 复活在主基地。
